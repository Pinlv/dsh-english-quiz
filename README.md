# 英语填空（English fill-in-the-blank）

在 DSH 聊天里，当 agent 想考你英语时，输入区会换成一整张填空卡：多句、多空、中文翻译，一次填完再提交。判分在本地完成，agent 只讲错题，并按错因继续出一组。

四种题型：

- **句子**：一组 4–6 项，每项是一个单词填空句，或者一句中译英；两种可以混在同一张卡里。
- **段落**：一整段短文，3–10 个空，只有这一题。
- **自由表达**：一个主题（例如“介绍一下你自己，以及你平常工作用什么技术栈”），下面一个大输入框，写一整段英文；提交后 agent 逐句点评。
- **翻译**：一句中文（例如“我的名字是 Max”），一个英文输入框；单独成卡时用这个模式。

每句/每段都有一个**小喇叭**：答题时朗读你当前填的句子/段落（填完就是连贯的一句），结果态朗读填好的正确句子。小喇叭旁边有**语速**选择：`×1`、`×0.8`、`×0.5`，选一次会记住。自由表达的答案提交后，结果卡上的小喇叭可以朗读你自己写的段落。

## 安装

需要 DSH 0.2.x 的 Web GUI。

1. 左侧「插件」→「添加插件」。
2. 输入 `dsh-english-quiz`，安装后启用。
3. 刷新页面；新会话里直接说“练一组”即可。

也可以让 agent 用 `plugin_manager` 的 `install_bundle`，target 填 `dsh-english-quiz`。安装后如果提示需要重启，重启一次 DSH。

## 用法

直接说：

- 练一组填空
- 练一组，混两道中译英
- 练 5 句，考一般过去时
- 来一段话的填空
- 翻译这句话：我的名字是 Max
- 用英语介绍一下你自己，以及你平常工作用什么技术栈
- 只练上一组错的地方

agent 会调用 `english_quiz` 工具，卡片出现在输入区。填空卡填完点 **提交**；翻译卡按 `Enter`；自由表达卡写完后点 **提交**（或 `Cmd/Ctrl+Enter`）。

## 交互

| 操作 | 行为 |
|---|---|
| `Tab` / `Enter` | 跳到下一个空；翻译卡按 `Enter` 直接提交 |
| `Cmd/Ctrl+Enter` | 提交整张卡（自由表达是在文本框里提交） |
| 小喇叭 | 播放句子/段落；答题态读你当前填的内容，结果态读正确句子 |
| 语速 | `×1` / `×0.8` / `×0.5`，对整张卡生效并记住选择 |
| 统计 | 会话头部的「英语统计」页签，打开跨会话统计面板 |
| 提交 | 填空一次判完所有空；翻译判整句；自由表达把整段文字交给 agent |
| 巩固这 N 个错点 | 带着错点清单回到 agent，生成下一组 |
| 换一组 / 换一句 / 换一个主题 | 同考点换语境、换一句翻译，或换一个自由表达主题 |
| 结束 | 收起卡片 |

- 中文翻译默认显示在每句下面；段落模式显示整段翻译。
- 空着也能提交，未作答单独标灰。
- 中文输入法组词时按 Enter 不会误跳空或误提交。
- 段落模式用 `\n` 分行，卡片按段落排版。
- 自由表达显示主题、可选要求、字数统计；写不出可以先写 3–4 句。

## 出题约定

- **句子**：4–6 项，填空或翻译混排；建议至少 1 个填空 + 1 个翻译。填空题每句 1–2 个**单词**空，总空数 ≤ 8；翻译项一句中文 + 1–4 个可接受英文译法。
- **段落**：1 段（3–5 句、30–70 词），3–10 个**单词**空，配一整段中文翻译。
- **自由表达**：1 个主题 + 可选要求（例如“至少 4 句”“用上 work with”）+ 建议字数；主题来自你已学过的工作/生活场景。
- **翻译**：1 句中文 + 1–4 个可接受的英文译法；一句一卡，判完整句。
> `PROGRESS.md` / `RECORDED.md` 是可选的：工作区有这两份文件时，只考其中“已覆盖”的语法点，词汇也从中取；没有就按你指定的考点生成。

- 如果工作区有 `PROGRESS.md`，只考其中“已覆盖”的语法点，最多带 1 个薄弱点。
- 如果工作区有 `RECORDED.md`，除答案外的词优先来自其中出现过的词汇。
- 每空可以有多个可接受答案；判分时大小写、全半角、句末标点、缩写（`I'm` = `I am`）都会归一化。

## 判分与讲解

- 填空卡：判分在 Host 侧完成，答案不会进入浏览器卡片；工具返回里带每个空的实际填写内容和对错，agent 只讲错题。
- 混排卡：填空题按空判，翻译项按整句判；结果卡分别显示“空 x/y”和“译 a/b”，agent 一起讲。
- 自由表达：没有本地判分，整段文字交给 agent；agent 按内容覆盖、语法、搭配和自然度给 2–3 条具体修改，并给一个简短示范版本。
- 翻译：本地按整句归一化比对（大小写、空白、全半角、句末标点、缩写），命中任一可接受译法就算对；agent 对错句讲具体差异。
- 结果卡会把差异标红：正确答案里缺的词或字母红色加粗，你的答案里多余或错的字符红色删除线；翻译、单词填空和独立翻译都适用。
- 如果本地判分把你其实正确的写法判错了，直接在聊天里说，agent 会改判。

## 进度与统计

- 每次提交都会追加到 `progress/quiz-log.jsonl`，保留最近 **2000** 条。
- 开新会话、开始练之前，agent 会先调 `english_progress` 读汇总，按最近的薄弱点出题；你也可以直接问“我最近怎么样”。
- 会话头部的「英语统计」页签打开面板：大号总正确率、练习组数、连续练习天数、待巩固考点、14 天答题柱状图、Anki 复习（14 天复习、通过率、学习时长、主要 deck）、考点明细表、接下来练（可复制练习清单）、最近错题和拼写记录。
- 统计面板和「对话」「轨迹」「统计」并列，是一个独立页面，不是弹窗；加载、空、错误、有数据四种状态都有。
- 拼写错（例如 `delopyed` → `deployed`）会**单独标黄、单独记录**，但当前仍判错，不会自动算对。
- 插件练习日志和 Anki 的调度无关；它只影响我出题和讲解，不写回 Anki。Anki 复习统计是只读导入，见下一节。

## 导入 Anki 复习

统计页的「Anki 复习」面板读 `progress/anki-stats.json`。导入最近复习：

```bash
python3 scripts/import-anki-stats.py
```

- 默认读 `~/Library/Application Support/Anki2/账户 1/collection.anki2`，先把数据库（含 WAL）复制到临时目录再读，不会锁 Anki，也不修改原库。
- 可用 `--db PATH` 指定其他 collection.anki2，用 `--out PATH` 改输出位置。
- 统计最近 14 个自然日的复习张数、Again 次数、通过率、学习时长和每日柱状图；另给累计复习次数、学习库卡片数和近 30 天主要 deck。
- 通过率按非 Again 计算：`Again` 算未通过，`Hard / Good / Easy` 算通过。
- 写 `progress/anki-stats.json`；刷新「英语统计」页签即可看到，不用重启。Anki 有新复习后重跑脚本，或在对话里说“重新导入 Anki 统计”。
- 插件答题统计和 Anki 复习统计分开展示，不混在一起。

## 限制

- 卡片只在当前会话、当前浏览器里显示；刷新页面会丢掉未提交的草稿，结果卡也会消失（聊天里的讲解仍在）。
- 一次只允许一张待答卡；提交或结束后才能再出下一组。
- 默认 600 秒不提交会自动取消（可在工具参数里调整，最大 3600 秒）。
- 判分是确定性的字符串比较，不做拼写模糊匹配；有歧义的答案请让 agent 提供多个可接受写法。
- 自由表达没有本地分数，靠 agent 的语义点评；字数只是建议，不是硬性限制。
- 发音用浏览器自带的 `speechSynthesis`：可用性、音色和清晰度取决于浏览器和系统；没有英文语音的浏览器点小喇叭不会出声。
- 答题态的朗读读的是你当前填的内容；空着的位置自然停顿，不会读出正确答案。

详细设计与后续阶段见 [DESIGN.md](https://github.com/Pinlv/dsh-english-quiz/blob/main/DESIGN.md)。
